# 🎂 ימי הולדת במשפחה

דף פשוט לניהול ימי ההולדת של המשפחה, עם תזכורת חודשית במייל ושליחה בלחיצה לקבוצת הוואטסאפ.

## איך זה בנוי

| חלק | איפה | תפקיד |
|---|---|---|
| `index.html` | האחסון שלך (סטטי) | הדף עצמו – תצוגה, הוספה/עריכה/מחיקה, וואטסאפ, הורדה ליומן |
| `apps-script/Code.gs` | Apps Script שמחובר ל-Google Sheet | ה-API (doPost) + מייל חודשי |
| Google Sheet | ה-Drive שלך | מסד הנתונים – אפשר לפתוח ולתקן ידנית |

**פרטיות:**
- **צפייה** – רק עם הקישור המשפחתי (`...#k=מפתח-סודי`). מי שמגיע לכתובת בלי המפתח רואה מסך נעול. הדף לא מכיל שום נתון, והמפתח נבדק בשרת.
- **עריכה** – צריך גם קוד עריכה קצר (4 ספרות). 10 ניסיונות שגויים = חסימה ל-10 דקות.
- **מחיקה היא "רכה"** – בגיליון העמודה `נמחק` הופכת ל-TRUE. לשחזור: משנים ל-FALSE.
- **יומן** – קובץ ה-.ics נוצר בטלפון של כל אחד, מהאנשים שהוא בחר. הבחירה לא נשלחת לשרת.

## הקמה (כ-15 דקות)

### 1. Google Sheet + Apps Script
1. צור Google Sheet חדש (שם לבחירתך, למשל "ימי הולדת").
2. בתפריט: **Extensions → Apps Script** (תוספים → Apps Script).
3. מחק את מה שיש ב-`Code.gs` והדבק את התוכן של [`apps-script/Code.gs`](apps-script/Code.gs).
4. ⚙️ **Project Settings** → סמן **Show "appsscript.json" manifest file in editor**.
   חזור לעורך, פתח `appsscript.json` והחלף בתוכן של [`apps-script/appsscript.json`](apps-script/appsscript.json).
   (זה קובע אזור זמן ישראל והרשאות מינימליות.)
5. שמור (Ctrl+S).

### 2. הפעלה ראשונה – `setup`
1. בסרגל העליון בחר את הפונקציה **`setup`** ולחץ **Run**.
2. יופיע חלון הרשאות → **Review permissions** → בחר את החשבון שלך.
   יופיע "Google hasn't verified this app" – זה רגיל לסקריפט פרטי שלך: **Advanced → Go to ... (unsafe)** → **Allow**.
3. ב-**Execution log** יופיעו:
   - `מפתח צפייה (VIEW_KEY)`
   - `קוד עריכה (EDIT_CODE)` – זה הקוד שתיתן למשפחה.
4. `setup` גם יצר לשונית **"בני משפחה"** בגיליון ואת הטריגר החודשי (1 לחודש, 08:00–09:00).

> רוצה קוד עריכה אחר? ⚙️ Project Settings → **Script Properties** → ערוך את `EDIT_CODE`.
> שם אפשר גם להוסיף `OWNER_EMAIL` אם התזכורת צריכה ללכת לכתובת אחרת.

### 3. פרסום כ-Web App
1. **Deploy → New deployment** → ⚙️ ליד "Select type" → **Web app**.
2. **Execute as:** `Me`   ·   **Who has access:** `Anyone`
   (זה בטוח: בלי המפתח הסודי השרת לא מחזיר כלום.)
3. **Deploy** → העתק את ה-**Web app URL** (נגמר ב-`/exec`).

> ⚠️ אם תשנה את `Code.gs` בעתיד: **Deploy → Manage deployments → ✏️ → Version: New version → Deploy**.
> ככה הכתובת נשארת אותו דבר. "New deployment" ייצור כתובת חדשה.

### 4. הדף
1. פתח את `index.html` ובראש הסקריפט הדבק את הכתובת:
   ```js
   const API_URL = 'https://script.google.com/macros/s/XXXX/exec';
   ```
2. העלה את `index.html` לאחסון שלך (כל אחסון סטטי עם HTTPS עובד).
   *חלופה:* GitHub Pages מהריפו הזה – Settings → Pages → Branch: `main`. בטוח, כי בקוד אין נתונים.
3. חזור ל-Apps Script → Project Settings → Script Properties → הוסף
   `SITE_URL` = כתובת הדף (למשל `https://example.com/birthdays/`).
4. הרץ את **`showSettings`** – בלוג יופיע **הקישור המשפחתי** המלא.

### 5. שיתוף עם המשפחה
שלח בקבוצה את הקישור המשפחתי (עם ה-`#k=...`) ואת קוד העריכה.
אחרי פתיחה ראשונה המפתח נשמר בטלפון, אז גם כניסה רגילה לכתובת תעבוד.

> קישור דלף? שנה את `VIEW_KEY` ב-Script Properties, הרץ `showSettings` ושלח קישור חדש.

## בדיקה – בלי לחכות ל-1 לחודש

| מה בודקים | איך |
|---|---|
| השרת חי | פתח את ה-Web app URL בדפדפן → "השרת פעיל ✓" |
| מסך נעול | פתח את הדף **בלי** `#k=` בחלון גלישה בסתר → 🔒 |
| טעינה | פתח עם הקישור המשפחתי → רואים את הדף (ריק בהתחלה) |
| קוד שגוי | "המשפחה" → הוספה → קוד לא נכון → הודעה + רעידה |
| הוספה/עריכה/מחיקה | עם הקוד הנכון. אחרי כל פעולה – בדוק שהגיליון התעדכן |
| הודעת וואטסאפ | הוסף מישהו עם יום הולדת החודש → "ימי הולדת" → "איך ההודעה תיראה?" → ואז הכפתור הירוק |
| מייל חודשי | Apps Script → הרץ **`testMonthlyEmail`** → המייל מגיע מיד |
| הטריגר קיים | Apps Script → ⏰ **Triggers** → `monthlyReminder`, Month timer, day 1 |
| יומן | "ליומן שלי" → סמן 1–2 אנשים → הורדה → פתח את הקובץ |

בדיקת ה-API מהטרמינל:
```bash
curl -L -H 'Content-Type: text/plain' \
  -d '{"action":"list","key":"המפתח-שלך"}' \
  'https://script.google.com/macros/s/XXXX/exec'
# → {"ok":true,"people":[...]}
```

## שאלות קטנות

- **שורה שהוקלדה ידנית בגיליון?** בסדר גמור – ממלאים שם פרטי, יום וחודש (ושנה אם יש). ה-`id` יתמלא לבד.
- **29 בפברואר?** בשנה רגילה מוצג ב-28.2, וביומן מופיע ביום האחרון של פברואר.
- **הגיל** מוצג רק אם יש שנת לידה.
- **ייבוא ליומן שוב אחרי שינויים** – מורידים קובץ רק עם האנשים החדשים, כדי שלא יהיו כפילויות.
- **אנדרואיד** – אפליקציית Google Calendar לא פותחת קבצי .ics. מייבאים מהמחשב: calendar.google.com → ⚙️ הגדרות → ייבוא וייצוא.
